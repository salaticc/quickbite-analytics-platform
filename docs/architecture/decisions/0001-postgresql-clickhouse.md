# ADR-0001 · PostgreSQL для транзакций, ClickHouse для аналитики

**Статус** — принято для MVP Stage 1.

PostgreSQL хранит транзакционные записи и обеспечивает PK, FK, `UNIQUE` и атомарные операции. ClickHouse хранит телеметрию, аналитические копии и впоследствии витрины dbt. На новом этапе пакетная выгрузка будет читать один согласованный снимок PostgreSQL и заменять landing-таблицы после проверки. Повтор того же входа воспроизводит тот же набор данных.

| Вариант | Компромисс |
| --- | --- |
| Только PostgreSQL | Одна база и простое развёртывание, но отчётные сканы делят ресурсы с продуктовой записью |
| Только ClickHouse | Одна аналитическая база, целостность транзакционных ключей пришлось бы контролировать в приложении |
| PostgreSQL и ClickHouse с batch | Две базы и задержка до следующей загрузки. Логику повторов легко проверить на полном наборе |
| PostgreSQL и ClickHouse с CDC | Меньшая задержка. Появляется управление слотами, порядком WAL и повторной загрузкой истории |

Stage 2 создаёт инфраструктуру, схемы и seed. Переход на CDC, отдельный каталог релизов и атомарная публикация набора витрин рассматриваются после измерения нагрузки и требований к свежести. Окна A/B и дизайн DiD уточняются в протоколах конкретных исследований.
